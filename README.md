# Finance Calculator
Basic text-based finance calculator to help calculate savings.

## Overview
*Finance Calculator* is a custom calculator used for basic savings. It takes user input to calculate the gross pay between the start of the current fiscal year and an inputted deadline, then calculates the amount of tax to be paid on the forecasted earnings. The user can provide any daily, weekly or monthly expenses that are recurring to be accounted for in the final savings figure, which are deducted from the pay after tax. The script then outputs final pay for the given period, following tax and recurring expense deductions. This is a very basic model to showcase the logic behind such a system.

## Key Features
- Custom UK tax calculator
- Transparent insight into income after tax and expenses
